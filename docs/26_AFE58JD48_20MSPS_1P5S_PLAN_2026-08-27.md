# AFE58JD48 + TSW14J50：20 MSPS／1.5秒候選方案

日期：2026-08-27
用途：流體仿體PW Doppler與數字鏈路驗證；不接人體、不作臨床用途。

## 1. 核心結論（2026-08-28重新排序）

20 MSPS在AFE58JD48的ADC clock規格範圍內，而且容量計算支持至少1.5秒的單塊raw-lane記錄：

```text
33,554,432 samples/lane ÷ 20,000,000 samples/s
= 1.6777216 s
```

把1.5秒作為工程驗收目標，可留下約0.178秒、10.6%的同步、濾波暫態與邊界裕量。要達到1.5秒，實際HSDC lane sample basis必須不高於：

```text
33,554,432 ÷ 1.5 s = 22.3696 MSPS
```

但是，2026-08-28實際收到並核對的TI附件明確只適用於`60 MHz + PLL40x + Demod + Decimation=32`，其NCO約486.145 kHz。郵件建議的`20 MHz / 160x`成套配置不在ZIP內。不能只把AFE或HSDC GUI中的60 MHz改成20 MHz，也不能沿用原CFG、INI、firmware、lane mapping或separator。

公開器件資料顯示20 MSPS是ADC clock下限；從JESD lane-rate角度，20 MSPS不能直接沿用40x packing。`PLL160x`是滿足lane-rate範圍的一個技術候選，但是否支持本項目的Demod、Dec=32、TSW14J50 firmware與separator，必須由TI確認和交付，不能自行拼接既有160x INI。

## 2. 方案分層

| 方案 | 狀態 | 單塊時間 | 用途 |
|---|---|---:|---|
| 60 MHz、PLL40x、Dec=32 | TI已說明的基準 | 約0.559 s | raw-lane與separator基線、短時Doppler |
| 20 MSPS、Dec=32、匹配PLL待TI確認 | 候選 | 理論1.678 s，目標≥1.5 s | 較長短時ensemble、約15,000 pulses@10 kHz |
| FPGA range-gated slow-time I/Q | 最終長時方案 | 10–60 s或更長 | 至少3個心動週期、連續PSV/EDV |

20 MSPS方案是有條件的中間方案，不是目前的首選實驗入口，也不取代最終長時slow-time後端。當前先完成TI 60M/40x原包、歷史16通道映射與短塊PW Gate；只有TI交付完整20M/160x包時才投入驗證。

## 3. 20 MSPS對PW Doppler的影響

對2–4 MHz超聲中心頻率：

- 2 MHz約10 ADC samples/cycle；
- 4 MHz約5 ADC samples/cycle；
- Nyquist頻率為10 MHz，可保留2–4 MHz主頻，但不應假設高次諧波仍完整；
- Dec=32的名義complex sample rate為625 kSPS；
- 若separator的時間映射符合`Fs/32`，名義軸向sample spacing約為`1540 / (2 × 625k) = 1.23 mm`。

原方案的1.0–1.5 mm range gate在這個sample spacing下可能只有約1個輸出sample。因此TI必須確認分離後sample interval、first-valid-sample與FIR/group delay；之後再以10 mm和20 mm反射體實測深度零點及解析度。

1.5秒在75 bpm時只有約1.88個心動週期，所以可用於較長短時Doppler，但通常仍不能滿足「單一連續記錄至少3個周期」的正式PSV/EDV Gate。若目標不變，仍需FPGA range-gated slow-time I/Q。

## 4. 向TI索取的完整交付

要求TI提供或確認一套不可拆分的20-MSPS配置：

1. 完整AFE58JD48 CFG，包括20-MHz ADC/LMK clock tree、Demod與Decimation=32設定；
2. 匹配的TSW14J50/HSDC Pro INI及所需RBF firmware；
3. 正確PLL mode、Subclass、LMFS/K、lane rate、active lane及lane-to-HSDC-column mapping；
4. 推薦AFE GUI、HSDC Pro版本及冷啟動／初始化順序；
5. HSDC `ADC Output Data Rate`應填的精確值；
6. `33,554,432 samples/lane`在20 MSPS時是否確實表示1.6777216秒；
7. raw BIN/CSV維度、數值格式、lane順序與預期檔案大小；
8. 匹配的separator/frame-assembly script及操作說明；
9. 分離後16個物理通道的I/Q順序、每個component精確samples、sample interval與group delay；
10. 若20 MSPS不支持，提供最低且不高於22.37 MSPS的驗證配置，或其他能取得至少1.5秒單一連續記錄的配置。

本訴求不是關閉8個AFE通道。所有16個物理通道都應在separator輸出中各出現一次，且無duplicate或missing。

## 5. 收到TI文件後的驗收順序

### Gate 0：歸檔與安全

- TX高壓OFF、CW OFF、`TX_BF_MODE=0`；
- 保存原始附件檔名、大小與SHA-256；
- 不覆寫60 MHz已知基準；
- 不混用20/40/80/160x、Subclass或不同Decimation的CFG/INI/firmware。

### Gate 1：clock與JESD link

- 核對ADC clock實測／readback為20 MSPS；
- 核對PLL mode、lane rate、LMFS/K、Subclass和firmware version；
- CGS/ILA/link與DDR初始化PASS；
- link PASS只表示建鏈成功，不表示channel unpacking正確。

### Gate 2：raw lane與捕獲深度

- 先捕獲65,536 samples/lane，核對TI指定active lanes與zero/padding lanes；
- 再依次測1M、8M與33,554,432 samples/lane；
- 完整capture實測時間≥1.5秒；
- 核對raw bytes、CSV rows、首／中／尾段連續性及檔案SHA-256。

### Gate 3：separator與16通道身份

- 保存separator名稱、版本、SHA-256及完整命令；
- 輸出16組`ChN_I/Q`，每個物理通道只出現一次；
- 無bit-exact duplicate、missing、固定碼或無法解釋的長度差；
- 記錄精確I/Q order、sample interval及被裁掉的同步／濾波樣點。

### Gate 4：已知tone與深度

- 逐通道輸入`f_NCO - 50 kHz`、`f_NCO`、`f_NCO + 50 kHz`；
- 驗證I/Q正負頻率、共軛規則與物理通道身份；
- 以10 mm／20 mm反射體量測first-valid-sample、group delay與range spacing。

### Gate 5：短時流體仿體

- 固定角度與range gate；
- 零流、正流、反流測試；
- 反轉流向時頻譜符號必須反轉；
- 1.5秒block只報短時表觀速度；不足3個周期時不報正式多周期PSV/EDV。

## 6. 決策

- 20 MSPS只列為達到約1.6秒的vendor-dependent次級候選，不能排在已交付60M/40x基線之前；
- 在TI提供匹配的完整配置前，不進行手工clock／PLL／INI拼接；
- 若TI無法提供≤22.37 MSPS的驗證配置，標準HSDC路徑不能可靠實現1.5秒；
- 即使20 MSPS達到1.6秒，也不能用跨次EXT_TRIG捕獲拼接非重播PW slow time；
- 若最終要求至少3個心動週期或≥3秒，直接轉入FPGA range-gated slow-time I/Q。
