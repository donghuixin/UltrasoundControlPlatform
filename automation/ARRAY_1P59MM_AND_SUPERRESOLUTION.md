# 1.59 mm 陣列：角度、相位與超分辨率選擇

## 結論

你的 1.59 mm 中心距在 2.5 MHz 下不是一個可無混疊掃描的密集陣列。取聲速 1540 m/s，波長約 0.616 mm，因此 `d/lambda = 2.58`。即使 0° 發射，也會在約 `+/-22.8°` 出現第一級柵瓣；掃到 `+10°` 時，最近的另一個空間解約在 `-12.3°`。

目前建議：

- 日常掃描角：`-8°...+8°`，步長 2°。
- 實驗最大角：`-10°...+10°`，重建顯示視場也限制在這一範圍。
- 若出現明顯鏡像/假反射，先縮到 `+/-6°`，不要繼續擴大角度。
- 4 MHz、5 MHz 會使空間混疊更嚴重，不能靠相位表修好。

## 為什麼舊延時表要重算

相鄰陣元真時間延時為：

`delta_t = d * sin(theta) / c`

使用 1.59 mm、1540 m/s、5 ns/count，可得：

| 角度 | 相鄰延時 | 約合 count |
|---:|---:|---:|
| 2° | 36.0 ns | 7.2 |
| 4° | 72.0 ns | 14.4 |
| 6° | 107.9 ns | 21.6 |
| 8° | 143.7 ns | 28.7 |
| 10° | 179.2 ns | 35.8 |

10° 時 8 陣元首尾約相差 1.254 us，也就是 2.5 MHz 載波的 3.14 個週期。因此應使用 TX7316 的完整真延時 count，不能只把相位取模到 0...360°。

`tx7316_hsdc_batch_capture.py` 會逐陣元量化，不是簡單地把四捨五入後的相鄰 count 重複累加，所以累積角度誤差更小。

## 物理陣列重設計

2.5 MHz 下：

- 若要求整個可見角度都無柵瓣，理想 pitch 不超過 `lambda/2 = 0.308 mm`。
- 若只要求 `+/-10°` 掃描範圍無柵瓣，pitch 應不超過約 `lambda/(1+sin10°) = 0.525 mm`。
- 現有 1 mm 寬陣元也大於上述 pitch，下一版需要更窄的陣元與更小 kerf，而不只是縮小中心間隔數字。

## 哪些“超分辨率”值得做

按實用優先順序：

1. **相干多角度平面波複合 + DAS/DMAS + coherence factor**
   - 這是最應先做的方案。它提高對比度並壓低旁瓣，但嚴格說不是突破衍射極限。
   - 必須先有共同硬件觸發；目前每次手點 Capture 的資料只能軟對齊，不能保證跨角度相位一致。

2. **SLSC（short-lag spatial coherence）或 phase coherence factor**
   - 對凝膠內雜波、非相干噪聲有用，通常比直接上神經網絡更可靠。
   - 需要每個 RX 真正獨立且通道映射正確。

3. **MVDR/Capon、EIBMV/ESBMV**
   - 可縮窄主瓣並抑制部分旁瓣；需要對協方差矩陣做對角加載和空間平滑。
   - 只有 8 個接收通道時樣本很少；若還存在重複通道，矩陣會接近奇異，效果會很差。

4. **基於精確前向模型的稀疏重建（L1/FISTA/ADMM）**
   - 對少數點反射體可以做亞像素定位，並把 1.59 mm 的精確陣元坐標寫進 steering matrix。
   - 對散斑豐富的普通 B-mode 組織不一定成立；模型誤差會產生看似銳利但錯誤的結構。

5. **MUSIC/ESPRIT**
   - 只適合少量、彼此分離的點散射體或窄帶目標，不適合一般瀰漫散斑截面。
   - 可用凝膠中的細金屬絲/點靶先做算法驗證。

6. **ULM（ultrasound localization microscopy）**
   - 真正的超分辨率血流通常依賴微泡、數千幀、高幀率定位與運動校正。
   - 它不是對一組普通凝膠 B-mode RF 數據直接套算法就能得到；也不適合沒有可分離移動散射體的靜態凝膠。

不建議現在直接用深度學習“去柵瓣”。先完成通道校準、共同觸發、點靶實測 PSF 和盲測驗證，否則網絡很容易把假影變成看起來很真的假結構。

## 建議的算法開發階段

1. 0° 單角度 DAS，核對深度和通道次序。
2. 用點靶標定每通道固定時延、增益、極性；記錄實際陣元 x 坐標。
3. 接共同硬件觸發，做 `-8°...+8°` 相干複合。
4. 同一資料比較 DAS、DAS+CF、DMAS、SLSC。
5. 再做 MVDR；用點靶的主瓣寬度、最大旁瓣、定位偏差量化，不只看圖片是否“更銳”。
6. 若目標確實是稀疏點反射體，再做 L1 或 MUSIC；若目標是微泡慢流，另建 ULM 的長序列採集流程。
